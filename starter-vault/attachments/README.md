# Attachments

Knowledge Base에서 재배포가 허용된 첨부파일만 관리합니다.

권장 하위 구조:

```text
attachments/
├─ images/
├─ diagrams/
└─ public-docs/
```

원칙:
- 공식 PDF는 가능하면 원문 URL과 Source Registry로 관리합니다.
- 저작권·라이선스가 확인되지 않은 원문 파일은 저장하지 않습니다.
- 이미지와 도표는 의미 있는 파일명을 사용합니다.
- Obsidian `![[...]]` embed 사용 시 공개 사이트 빌드 호환성을 확인합니다.
