# Operational Commands

Knowledge Base Generator는 생성 이후의 운영 작업도 같은 CLI에서 수행하는 방향으로 확장합니다.

- `kbgen init` — 새 Knowledge Base 생성
- `kbgen research` — 연구계획 또는 grounded source discovery
- `kbgen audit` — Evidence/metadata 품질 감사
- `kbgen doctor` — Vault 구조와 validator 상태 확인
- `kbgen github` — GitHub CLI를 이용한 repository bootstrap 계획/실행

기존 `kbgen "해상풍력"` 호출도 하위 호환으로 유지합니다.
